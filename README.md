# SMARTDOORLOCK

2024 한이음 ICT 멘토링 프로젝트

Raspberry Pi와 카메라를 활용한 얼굴인식 기반 스마트 도어락 및 스마트홈 IoT 시스템입니다.

## 주요 기능

- OpenCV Haar Cascade·LBPH 기반 얼굴 검출 및 인증
- 초음파 센서 기반 사용자 감지
- Firebase Storage 기반 인증 이미지 저장
- GPIO 기반 도어락 제어
- 반복 인증 실패 시 비밀번호 인증 전환

## Tech Stack

Python · Raspberry Pi · Picamera2 · OpenCV · Flask · Firebase · RPi.GPIO
